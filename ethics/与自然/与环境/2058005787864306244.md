# answer-2058005787864306244

> 原文：[https://www.zhihu.com/question/2057188903359098994/answer/2058005787864306244](https://www.zhihu.com/question/2057188903359098994/answer/2058005787864306244)

之前在谈法国极端高温的回答里说到过极端天气是关系到每一个人的危机，评论区里有无数人出来说“不关我事”。其实这件事和每个人的关系非常近。因为一旦发生极端天气，立刻就是几百万、几千万、上亿的人民受苦。极端的风灾、水灾、高热，绝不是玩笑。一旦超过了基础设施的抗灾设计标准，对基础设施有大面积严重摧毁，对我们的超高密度聚居社会是巨大的挑战。我不得不再把塞班的图重发一次——塞班自己是热带国家，他们当然有按照抗常规风暴的标准建设房屋。根据塞班岛现行的《建筑安全法规规则与条例》（Building Safety Code Rules and Regulations）：法定制导风速：所有涵盖在建筑安全法规内的建筑物或结构，其主体及任一部分在设计和建造时，必须能够承受至少 175 mph（约 282 km/h） 的基本设计风速（3秒阵风风速）。对应台风级别：这一标准超越了国际萨菲尔-辛普森飓风等级（Saffir-Simpson Scale）中最高的5级飓风/超强台风（5级标准为持续风速 >157 mph）。也就是说，塞班岛的永久性建筑在理论上能够抵御最高级别的超强台风。 特殊风区（Special Wind Region）：由于群岛包含复杂的山地和海岸地形，局部区域会因地形产生风流汇聚（风洞效应）。针对部分特定工程，规范还要求由专业工程师进行专项气象和地形风速分析。然而近期袭击塞班岛等马里亚纳群岛的超强台风“巴威”（Super Typhoon Bavi）达到了萨菲尔-辛普森飓风等级中最高的5级，最高持续风速达到了约 175至180英里/小时（约282至290公里/小时）。塞班已经是按照历史经验的最高等级做的建设，然而这是它的结果：这已经是万幸了，它这毕竟房屋的主体结构还大规模保留着，实现了0人死亡——幸亏飓风可以提前预警，这些高标准建筑没有白修。但在提高标准前和标准覆盖外的建筑真的是一扫而空。然而，这对我们却不是一个纯然的坏消息。如果极端天气开始频繁肆虐，大量的生命财产损失连篇累牍的刷版，气候问题就不再只是“北极熊灭绝”“必须得买空调”这么无关痛痒的问题，而是坐地铁会不会突然被淹死，停在地下车库和路边的车会不会一夜之间半损全损，会不会有龙卷风明天突然把整栋楼吹成空壳，严重的冰灾会不会一夜之间把全地区的电缆都扯断、树木都摧毁、水管都冻爆这种不止关痛痒、甚至关生死的问题。如果这些灾害出现次数足够频繁，气候问题终将超越地缘政治问题成为国际秩序的新中心问题——就像那几年疫情突然成为核心问题一样。到时候世界所有国家就要被迫进入激烈的文明转型之中。而不管是按照更高的抗灾标准更新基础设施，还是将现有的能源结构大规模的向绿电迁移，还是在世界转型期间填补天量的产能缺口，这都是几乎纯然的物理性问题，这些都必然导致全球制造业国家的国际地位大幅的攀升。我们是制造业第一大国，是新能源领域的统治者，如果气候问题被历史选定成为下一世代的强制主题，我们是肯定要担当更关键的领导角色。怎么可能与你没有关系呢？不过话虽如此说，这毕竟是苦难滔天的画面，作为一个人类，还是祈祷世界平安吧。希望我们能在气候问题上早点认真起来，而不是非要等到洪水滔天，尸横遍野之后再来追悔莫及。
