# 正念

> 原文：[https://www.zhihu.com/question/1930392746654405330/answer/1930703435319211536](https://www.zhihu.com/question/1930392746654405330/answer/1930703435319211536)  
> 赞 845 · 评论 41 · 2025-07-21

“正能量”固然好，但现在普遍的“正能量”的用法就约等于手机不插着线只能用半小时，全靠充电宝续命。充电宝们经常协议匹配不上，插也插上了，充电宝自己的电量直线下降，热得烫手，但手机就是充不进电，一拔就黑屏。这都还是好的，还有协议不匹配到一插就死机的。然后充电宝们发愁，要来问“到底应该怎么供电”。其实这不是供电的问题，也不应该视为供电的问题。在你的小手机把自己的电路修好、坏电芯换掉之前，输电几乎没有意义。人从来缺的都不是“正能量”，而是自己内生能量的机制。天生就有一百瓦的发电功率，即使遇到一些西北风自己也不会轻易发寒，遇到了一百瓦都压不住的寒风，才需要靠几个自带一百瓦输出的热源背靠背抱团来减少散热，这才是人应该有的常态。真正的问题是人内心自己的发热机制为什么失效了，是如何点燃这座反应炉。所以，家庭教育的核心是要和那些不断侵蚀人的积极性、刺激人的消极性的作斗争，是要修好人的电路，找到失效的升压芯片或者脱焊点，而不是仅仅靠“插电”、靠“提供正能量”去续命。你要的不是“正能量”，而是“正念”——那种能花悲痛为力量、化耻辱为勇气、化挫折为斗志、化失败为启发的思维结构。一勺海水教你头上，你当场熄火。浇我头上，我先给你把蓝绿藻滤出来存着培养，微生物留着养鱼，盐给你析出来做菜、铀235富集起来送反应堆，纯水还灌瓶给你卖了。差别在哪？我身上一堆渗透膜，一堆管路，一堆交易机制，一堆提炼机制，还有核反应堆。我不是露天的一堆柴，所以你不但浇不灭我，我还把你当矿采。我当然不缺“正能量”，恰恰相反，我还把锅炉废热送进居民区收暖气费好伐。这些过滤、蒸馏、提炼、加工、提纯的结构设施，就是“正念”，这是要花功夫从一片荒地上建设起来的。否则你真的是露天一堆柴，上面连个遮雨棚都没有，你真得要抱着我的暖气片生活。采暖费你交得起么？不要去“安慰”，而要给予真正的教育。真正的教育是个什么样子呢？是在教育之后，原本觉得自己倒霉的沮丧的人，不但发现自己多么幸运，而且还变得振奋、积极、跃跃欲试。那不是靠抱着别人的暖气片，而是靠教会它怎么用海水发电。ta心里的反应堆运转了，就不需要“正能量”了。这反应堆点不亮，靠USB输电没用。
