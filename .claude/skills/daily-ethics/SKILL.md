# 今日一问

用户要的是一道能拿来过的日子的问题，不是书单，不是通读计划。

## 抽篇

先跑，再读。不要自己随机点篇。

```bash
python3 .claude/skills/daily-ethics/scripts/daily.py
```

- 换一问 / 跳过今日：`python3 .claude/skills/daily-ethics/scripts/daily.py --skip`
- 只要某一类：`--l1 与自己` 或 `--l2 与恋人`
- 只要问题、先别答：仍先跑脚本，作答段省略

脚本会把当日篇目写入 本 skill 目录下的 `daily-log.csv`。默认跳过未归、馆务、无中文标题、正文过短的篇。不要改原文。

## 出题

`Read` 抽中篇的全文（用 JSON 里的 `path`）。根据标题和正文实际在答的事，写成一句对「你」说的生活问句，像「怎么减肥」「感觉自己很无能怎么办」。

- 问句必须是这篇（以及同题检索能接到的篇）答得了的。正文没有的处境，不要硬编成问。
- 不要把篇名、分类名、赞数写进给用户看的正文。
- 先单独一行写出问句，再作答。

## 作答

把这句问句当作用户刚问的，立即按 skill `ask-ethics` 检索并成文：再查索引、再 `Grep`、再读 3–8 篇，用原文口吻答「你」。抽中的这篇是种子，不是唯一出处。

用户说「只要问题」时，只出问句，一行即可，不要布置作业、不要预告明天。
